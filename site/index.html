What the two lights mean

A contract failure means a declared expectation is broken: a missing field, a changed series identity, a duplicate date, a late observation. A review signal means a value is unusual and a person should look. It does not mean the value, or the publisher, is wrong.

Does the alarm cry wolf?

The review rule flags a daily move when its robust z-score reaches 6. On the real series, 9 of 7,010 replayed days cross it. A bell-curve model of returns would predict almost none. Currency returns have heavy tails, so the rule is far more active than its threshold suggests, and a stricter or looser threshold changes the count a lot.

Epistemic boundary: what this cannot tell you.

Limits are part of the result. Read them before you read the numbers above.

  • Nine out of nine is a test, not a rate. The nine faults were written by the same author as the checks that catch them, so the 100% detection is a regression test. The 95% Wilson interval of 0.70 to 1.00 reflects only nine hand-made cases.
  • A clean file cannot fail. The replay uses one current vintage of the series, so zero contract failures is the expected outcome. It cannot reveal revisions that happened between past publications, and its 7,010 prefixes overlap, so they are not independent trials.
  • The review rule is a heuristic. The excess over a normal model mixes heavy tails, volatile periods and a scale estimated from 250 points. This audit does not separate them, and a signal never proves an error.
  • One series, one publisher. The monitor cannot see the ECB's unpublished inputs, judge economic correctness, or forecast anything.
  • Not checked. Other series, other thresholds chosen in advance, and any long prospective record: the live evidence branch holds only a few runs so far.
  • Post-hoc. The alarm audit was added after the frozen v1 release and is not preregistered.

Reproduce it yourself.

The code uses only the Python standard library. The ECB snapshot used for the replay is in the repository with its checksum.

python -m unittest discover -s tests -v
python scripts/generate_threshold_audit.py
