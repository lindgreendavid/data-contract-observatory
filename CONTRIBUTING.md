# Contributing

Changes are welcome when they preserve the distinction between contract failure, statistical
review, and substantive source error.

Before opening a pull request:

1. explain which protocol rule or implementation detail changes;
2. add a deterministic regression or synthetic mutation test;
3. run the full Python test matrix locally where practical;
4. update the protocol version for changes to fields, thresholds, calendar rules, or interpretation;
5. keep credentials, downloaded raw data, and unrelated files out of the commit.
